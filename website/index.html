十个模块，一张工作台

多开时数据目录互相隔离，任务日志可导出。Session 与同名 json 可一键配对导入，号池和任务都在你自己的电脑上跑。

01 / ACCOUNTS

账号中心

手动登录、导入 Telethon session，支持与同名 json 一键配对。可转 Telegram Desktop 的 tdata。批量改资料，单账号独立广告语。

02

群发 / 加群

文本、图片、文件、转发频道消息（可藏源）。自动加群，间隔与休息可配。

03

采集

抓群成员，按关键词搜公开群。结果落在本地「采集」目录。

04

私信

按用户名或手机号批量私信，失败对象可导出，遇限制立即停号。

05

拉人 / 炒群

批量邀请入群；多号自动互动，把冷群炒热。

06

监控与筛群

关键词监控、自动回复；按条件过滤目标群。还有链接提取、评帖、克隆频道。

四步开航

先拿到安装包和卡密，再在软件里登录邮箱、激活授权。API 与代理在设置页配置，号池始终在你磁盘上。

01

下载安装

Windows 桌面端。若杀软误报，把安装目录加入白名单即可。

02

注册登录

邮箱验证码注册。同一账号新登录会踢掉旧会话，避免共享。

03

激活卡密

把购买的卡密贴进软件，时长累加到到期日。断网超过 24 小时会锁定任务。

04

导入开跑

填自己的 api_id / api_hash，配好代理，导入 session 后即可群发与采集。
